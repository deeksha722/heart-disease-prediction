# Heart Disease Prediction Using Machine Learning

## 📌 Overview

A machine learning project that predicts the possibility of heart disease based on patient health data. The project uses classification algorithms and a Streamlit web application to generate predictions.

## 🛠️ Technologies Used

* Python
* Pandas and NumPy
* Scikit-learn
* Matplotlib and Seaborn
* Streamlit

## ⚙️ Project Workflow

* Performed data exploration and preprocessing.
* Encoded categorical features for model training.
* Trained and evaluated Logistic Regression, Decision Tree, and Random Forest classifiers.
* Saved the trained Random Forest model using Pickle.
* Developed an interactive Streamlit application for predictions.

## 📊 Model Performance

* Logistic Regression: 87% accuracy
* Decision Tree: 100% accuracy
* Random Forest: 100% accuracy

*Note: These are the results observed during development. Further validation is needed to assess generalization and investigate the unusually high accuracy scores.*

## 🚀 Run Locally

1. Clone this repository.
2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```
3. Start the application:

   ```bash
   streamlit run app.py
   ```
